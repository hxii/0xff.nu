Saisho Edit is a very simple (in harmony with Saisho) post editor for [Saisho](/saisho). The primary purpose is to allow creating and editing new posts from anywhere using the web.

![Saisho Editor](https://0xff.nu/i/Uneven-146a625df14bd7ad.jpg)

Since Saisho itself is a very light engine, the editor follows suit.
For the time being, all Saisho Edit has is:
- Listing all the MD files.
- Load/save functionality.
- A textarea for your writing.
- PHP session auth.
