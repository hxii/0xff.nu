This is a very simple logger class that was written to be used with the updated [Yotpo WooCommerce Plugin](https://github.com/hxii/YRFW)
It's one of those things I've decided to write as I navigate the swamp that is learning PHP.

## Wat do?

- Debug level support (currently only two levels implemented).
- File size control and renaming old files (kinda works?)
