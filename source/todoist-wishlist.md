---
title: Todoist Wishlist
date: 2025-03-11
tags: productivity, todoist
---
Todoist is great, but in my humble opinion it is missing some (a few of them basic) features
that could make it that much better. I decided to consolidate them into a list.

- [ ] Task duration timer - i.e. I thought washing dishes would take me 20 minutes, while it actually took 10.
- [ ] Task dependencies/prerequisites - prevent a task from being completed until all sub-tasks have been completed.
- [ ] Pin/bookmark task - grouping/sorting aside, some tasks HAVE to be at the top.
- [ ] Task status - ability to "pause" a task, for example. Arguably could be addressed via labels.
- iOS Shortcuts
	- [ ] Get task
	- [ ] Edit task
	- [ ] Delete task
	- [ ] Ability to freely add labels (instead of a predefined list) 
- Filters
	- [ ] Activity filter, e.g. `!activity: 7 days`
	- [ ] Aliases for filters
	- [ ] Regex search, e.g. `search:/youtube\.com|youtu\.be/`
- Grouping
	- [ ] Grouping by multiple parameters - e.g. `group: section, priority`
	- [ ] Grouping by specific labels - e.g. group by `@☀️` and `@🌙`.
